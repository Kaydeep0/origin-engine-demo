# Origin Engine — public demonstration

A static demonstration of **Origin Engine**, an experimental research instrument that tracks
scientific propositions over time under strict historical discipline.

**Live:** https://kaydeep0.github.io/origin-engine-demo/

- `index.html` — project overview: purpose, architecture, capabilities, limitations
- `app/` — the interactive prototype

## This is a research prototype, and its central hypothesis failed

Origin Engine was tested against a pre-registered protocol, with the method and all candidate
rankings frozen under SHA-256 before any answer key was retrieved. The result was **negative**:
the method recovered less documented scientific ancestry than simply ranking papers by citation
count (16.0% vs 32.0% at the same budget). That result is published rather than buried.

It has **no demonstrated predictive performance** and provides **no investment recommendation,
valuation or probability of success**.
